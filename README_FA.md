# پروژه اندروید کتابخانه آثار

نسخه آغازین یک اپلیکیشن بومی اندروید با Kotlin و Jetpack Compose.

## امکانات فعلی
- رابط فارسی و راست‌چین با طراحی رسمی و حرفه‌ای
- فهرست اولیه کتاب‌ها
- جست‌وجوی عنوان و توضیح
- فیلتر دسته‌بندی
- صفحه جزئیات و شناسنامه کتاب
- علاقه‌مندی‌ها در طول اجرای برنامه
- انتخاب PDF از حافظه دستگاه و مطالعه صفحه‌به‌صفحه با PdfRenderer اندروید
- مجوز اینترنت و آماده‌سازی اولیه برای اتصال به سرویس آنلاین

## وضعیت آنلاین و آفلاین
این نسخه با داده‌های نمونه داخل برنامه به‌صورت آفلاین اجرا می‌شود. کاربر می‌تواند فایل PDF موجود روی دستگاه را از صفحه جزئیات کتاب انتخاب کند و داخل برنامه، صفحه‌به‌صفحه بخواند. فایل PDF به سرور ارسال نمی‌شود. دریافت PDF از سرور و اتصال آنلاین هنوز به API و سرویس واقعی متصل نشده است. برای تکمیل حالت ترکیبی آنلاین/آفلاین باید:
1. یک API امن برای فهرست کتاب‌ها و جزئیات ایجاد شود.
2. پایگاه داده محلی Room به برنامه اضافه و همگام‌سازی پیاده‌سازی شود.
3. پنل مدیریت برای ورود و اصلاح کتاب‌ها ساخته شود.
4. نشانی سرور و سیاست کش/به‌روزرسانی مشخص شود.

## اجرای پروژه
1. Android Studio نسخه سازگار با Android Gradle Plugin 8.7.3 را نصب کنید.
2. پوشه پروژه را باز کنید.
3. اجازه دهید Gradle Sync انجام شود.
4. یک شبیه‌ساز یا دستگاه اندرویدی متصل کنید.
5. Run را بزنید.

## ساخت فایل‌ها
از منوی Build در Android Studio:
- Build APK(s) برای فایل نصب آزمایشی APK
- Generate Signed Bundle / APK برای ساخت نسخه امضاشده انتشار
- برای فروشگاه‌ها معمولاً Android App Bundle (AAB) لازم است؛ شرایط هر فروشگاه را جداگانه بررسی کنید.

## نکته مهم درباره محتوا
فهرست داخل برنامه فقط داده آغازین است. نوع انتساب برخی آثار، ناشر، سال، شابک و تعداد صفحات باید با شناسنامه نسخه معتبر بررسی شود. اطلاعات تأییدنشده عمداً «نیازمند بررسی» درج شده‌اند. پیش از انتشار عمومی، مجوز استفاده از جلدها و متن‌های کامل کتاب‌ها و نیز سیاست حریم خصوصی باید تعیین شود.

## نسخه ۰٫۳ — منبع PDF رایگان
- عنوان «بانک جامع نامه‌های مقام معظم رهبری» به فهرست نمونه اضافه شده است.
- دکمه «مشاهده PDF از منبع منتشرکننده» فایل را از پایگاه قائمیه باز می‌کند؛ فایل در APK کپی یا بازنشر نشده و از منبع اصلی دریافت/مشاهده می‌شود.
- پایگاه قائمیه در صفحه معرفی اثر، هزینه مشاهده را رایگان اعلام کرده و در بخش «حقوق مؤلفان و ناشران» نوشته محتوای خود را با هماهنگی و مجوز کتبی عرضه می‌کند و نشر رایگان مطالب و نرم‌افزارهای سایت را مجاز دانسته است.
- برای استفاده آفلاین، کاربر می‌تواند فایل PDF را از منبع اصلی دریافت کند و سپس از دکمه «انتخاب و مطالعه فایل PDF» در برنامه باز کند.
- این نسخه هنوز APK امضاشده یا خروجی آماده انتشار نیست و باید در Android Studio کامپایل و آزمایش شود.


## ساخت APK آنلاین با GitHub Actions (بدون نصب Android Studio)
1. فایل ZIP را از حالت فشرده خارج کنید.
2. محتویات پوشه `ketabkhaneh-android` را در ریشه یک مخزن GitHub بارگذاری کنید (فایل `.github/workflows/build-apk.yml` نیز باید بارگذاری شود).
3. در GitHub وارد زبانه **Actions** شوید و workflow با نام **Build Android APK** را انتخاب کنید.
4. روی **Run workflow** بزنید؛ یا با push کردن کد به شاخه `main` ساخت خودکار آغاز می‌شود.
5. پس از پایان موفق، وارد اجرای workflow شوید و از بخش **Artifacts** فایل `ganjineh-andisheh-debug-apk` را دانلود کنید.

این خروجی یک APK آزمایشی (debug) است؛ برای انتشار در فروشگاه‌ها باید نسخه release را با کلید امضای اختصاصی بسازید. فایل کلید امضا و رمز آن را در مخزن عمومی GitHub قرار ندهید.
